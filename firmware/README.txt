Video:   HDMI 640x480x60Hz (HSTX / PicoDVI, DVI-Sock GP12-19)

FLASH:
1. Țineți apăsat BOOT + conectați cablul USB-C de PROGRAMARE (sus) — apare drive-ul RP2350.
2. Copiați (drag-drop) acest fișier .uf2 pe drive.
3. Placa se resetează singură. Alimentați din portul POWER, conectați monitor HDMI și tastatură USB.
4. Meniul: F1 (sau tasta meniu). 0-9/E = mașini, D = discuri/ROM-uri/CF, R = ROM custom.

Audio: PWM difuzoare (implicit), I2S experimental, HDMI monitor — selectabile din meniu.
